Kilolane Android tester (preview)

Install Kilolane
  1. Tap Install.
  2. Allow “Install unknown apps” for your browser if asked.
  3. Open the app, and updates arrive on their own.
  4. To pick up the latest preview update: fully close the app and reopen it, then close and reopen once more. You should see Charge and Ask as short tab labels, map pins, and a Try the demo button. If the tabs still say Charging and “Ask you…”, reinstall from this page, then reopen twice.

This is a free test version, Android only. iPhone users should use the test page instead.
